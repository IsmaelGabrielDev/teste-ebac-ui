# Teste de ponta a ponta com Cypress - Loja Ebac

### Realizando testes de ponta a ponta no site da Loja ebac no curso Engenheiro de Qualidade de Software

Ebac shop: http://lojaebac.ebaconline.art.br/

## Aplicativos necessarios:
- Node.js: Você encontra em - https://nodejs.org/en/

- Visual Studio Code ou qualquer editor de texto - você encontra em: https://code.visualstudio.com/download

- Git - você encontra em: https://git-scm.com/downloads

- Navegador Chrome ou de sua preferencia - você encontra em: https://www.google.com/intl/pt-BR/chrome/

### Extensões necessarias no Visual Studios:
- Cypress Snippets
- ES6 Mocha Snippets

## Clonando e execultando o  projeto completo direto em sua maquina pelo Visual Studios Code:

Via terminal, rode os comandos:
```bash
git init

git clone https://github.com/IsmaelGabrielDev/teste-ebac-ui.git

cd teste-ebac-ui
```

### Para instalar as pendiencias:
```bash
npm install
```
### Para executar o modo Headless via console:
```bash
npx cypress run
```

### Para executar via Dashboard:
```bash
npx cypress open
```
Após abrir o painel, selecione um dos navegadores (de preferência Electron) e siga as execuções.
